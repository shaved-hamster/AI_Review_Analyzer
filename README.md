
# AI Review Analyzer

Вебзастосунок для аналізу відгуків користувачів за допомогою штучного інтелекту.

## Можливості

- Аналіз тональності текстових відгуків.
- Визначення позитивних, негативних та нейтральних відгуків.
- Відображення результатів у таблиці.
- Формування статистики та діаграми.

## Технології

- Python
- Flask
- Hugging Face Transformers
- HTML
- CSS
- Chart.js

## Запуск проєкту

1. Створити віртуальне середовище:

   python -m venv venv

2. Активувати його:

   venv\Scripts\activate

3. Встановити залежності:

   pip install -r requirements.txt

4. Запустити застосунок:

   python app.py

5. Відкрити у браузері:

   http://127.0.0.1:5000
